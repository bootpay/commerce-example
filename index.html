NPM 방식

모던 JavaScript 프로젝트에 적합한 NPM 패키지 방식입니다. 번들러와 함께 사용합니다.

npm install @bootpay/bp-commerce-sdk
  • Tree-shaking 지원
  • TypeScript 타입 정의
  • 번들 최적화
